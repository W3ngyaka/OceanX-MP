Species photos for the info modal go in THIS folder.

- Name each file to match the "imageFile" column in ../SpeciesContent.csv
  (e.g. reticulated_damselfish.png, blacktip_reef_shark.png).
- PNG or JPG both work.
- These load at runtime from disk, so on the built app you can add/replace
  photos in this folder next to the .exe without rebuilding.

NOTE: This is for the SPECIES PHOTOS shown in the modal.
Your DESIGN assets (background, icons) are NOT here - import those into the
Assets folder normally and assign them in the Inspector.
